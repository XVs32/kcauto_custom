## 附錄 ‐‐ 在 POI 上跑 KC3

到頭來還是覺得 KC3 比 POI 的插件生態好用，  
所以就做了這個在 POI 裡跑 KC3 的 workaround。

原理很簡單：用一個空的舊版 Chromium 跑 KC3，  
再把 POI 的 API 複製過去餵給 KC3。

![kc3 on poi overview](assets/kc3_on_poi_overview.png)

---

### 依賴

你需要安裝：

* poi 瀏覽器（廢話）
* `poi-plugin-forwarder`
* 還支援 V2 manifest 的舊版 Chromium（我用的是 Version `138.0.7204.183`）
* KC3（也是廢話）

### 設定步驟

打開 `poi-plugin-forwarder`，  
啟用 `KC3 relay`。

![relay enable](assets/poi-plugin-forwarder-kc3-relay.png)

在 Chromium 裝好 KC3 之後，  
用以下參數啟動 Chromium：

```bash
chromium --app="http://127.0.0.1:9224/relay.html" --auto-open-devtools-for-tabs --disable-background-timer-throttling --disable-renderer-backgrounding --disable-backgrounding-occluded-windows --no-first-run
```

應該會看到像這樣的空白畫面。

![kc3 on poi overview](assets/kc3_relay_page.png)

接著就可以打開 KC3 的 F12 面板了。
