工具箱裡的 `tool/map/mapCoorUpdater.py` 可以協助建立地圖資料，執行此 Python 檔案所需的依賴項目列在 `tool/map/mapCoorUpdaterRequirement.txt` 中。

執行該工具，它會從 [KC3 原始碼](https://github.com/KC3Kai/KC3Kai/blob/master/src/data/edges.json) 擷取最新的地圖資料。  
請確保在 KC3 更新活動地圖資料後再進行此操作。

<img width="598" height="242" alt="image" src="https://github.com/user-attachments/assets/b8976682-3a61-4d20-a6de-43e3773bbf9e" />  

*地圖座標更新器*

填寫完基本資料後，需要定義每個節點的座標（參考：[issue#20](https://github.com/XVs32/kcauto_custom/issues/20) 及 [discussion#71](https://github.com/XVs32/kcauto_custom/discussions/71#discussioncomment-7713804)）：

1. 點擊地圖左上角。
2. 依照工具指引設定節點類型。  
   按下按鍵：  
    * `o`：可動點 (Option node)  
    * `a`：防空點 (Anti-air node)  
    * `s`：反潛點 (Anti-sub node)
    * `b`：BOSS 點  
3. 點擊各個節點。

## 節點 (Nodes)

為了讓 `kcauto` 能夠處理，所有節點都定義在 `data/combat/map_enum.json` 中。

幸運的是，你不需要手動將新增的節點加入該檔案。  
執行 `tool/map/maps_generater.py` 即可產生 `tool/map/map_enum.json` 。  
接著用 `tool/map/map_enum.json` 替換掉 `data/combat/map_enum.json` 即可。

## 地圖資料除錯

以防萬一你需要對 `E-X.json` 檔案進行除錯，
以下參考舊的 `E-5.json`。地圖資料定義了地圖中的節點、路徑與敵軍類型。

```json
{
    "world": "E",               // 活動地圖
    "subworld": 5,              // 第 5 海域
    "panel": 1,                 // 1 號面板（上方）。例如 E1〜E3 若都在第 1 頁時需要此項
    "page": 3,                  // 第 3 頁
    "enemy_context": [          // 此地圖出現的敵軍類型。提供資料給任務模組
        "subs",
        "carriers",
        "transports"
    ],
    "nodes": {                  // 所有節點的座標。相對於遊戲視窗（非瀏覽器或螢幕）左上角的偏移量
        "A": {
            "coords": [
                157,
                273
            ]
        },
        "L2": {
            "coords": [
                775,
                424
            ]
        }
    },
    "edges": {                   // 所有節點間的路徑。資料來源為艦隊Collection 的 API 
        "1": [
            "Start 1",
            "A"
        ],
        "37": [
            "V",
            "U"
        ]
    }
}
```
