# kcauto_custom

### ***最新ダウンロード (2026/07/27)は*** [***こちら***](https://github.com/XVs32/kcauto_custom/releases/tag/v3.2.0) 

***警告***：`kcauto_custom` は Windows 上でも動作するはずですが、元々 Linux 環境のために開発されたものです。互換性の問題について、修正は保証されません。

**[kcauto_custom](https://github.com/XVs32/kcauto_custom)** は、アーカイブされたプロジェクト [kcauto](https://github.com/perryhuynh/kcauto) をベースに、機能を追加・カスタマイズしたバージョンです。  
**kcauto** と比較して柔軟性は低いですが、自動化能力が強化されています。  
Python 環境を構築したくないユーザー向けに、実行ファイル (.exe) を提供しています。  
[Noro6](https://noro6.github.io/kc-web/#/aircalc) で艦隊や装備の構成を作成し、それを `kcauto_custom` で実行できます。  
このツールは、遠征、出撃、演習、修理・補給といった繰り返し作業を自動化し、時間を節約して効率を向上させることを目的としています。

### kcauto のオリジナル機能

* 遠征 (Expedition) &mdash; 遠征の自動化
* 演習 (PvP) &mdash; 演習の自動化
* 出撃 (Combat) &mdash; 出撃の自動化
* 基地航空隊 (LBAS) &mdash; 基地航空隊の自動派遣
* 艦娘切替 (Ship Switcher) &mdash; 出撃間に指定された条件に基づいて自動的に艦娘を入れ替え
* 艦隊切替 (Fleet Switcher) &mdash; 演習や出撃用の艦隊プリセットを自動切替
* 任務 (Quests) &mdash; 任務の自動管理
* 修理・補給 (Repair & Resupply) &mdash; 艦隊の修理・補給を自動化
* 統計 (Stats) &mdash; 各種操作の統計データを保持
* クリック追跡 (Click Tracking) &mdash; `kcauto` によるクリック操作の記録（オプション）
* 排程/手動停止 &mdash; 個別のモジュールまたはスクリプト全体の排程および手動での一時停止
* 艦これ猫対策とスクリプト自動復帰
* 航行、タイマー、クリック位置へのランダムな変動付与（反ボット対策）

### kcauto_custom の追加機能

* 実行ファイルの提供 &mdash; Python 環境の構築不要
* CUI (Character User Interface) &mdash; 日常的な使用に便利な CUI
* 明石修理モジュール &mdash; 明石による艦隊修理
* 工廠モジュール &mdash; 建造と開発の自動実行
* Noro6 対応 &mdash; Noro6 で計画した艦隊と装備セットアップを自動実行
* 装備切替モジュール &mdash; 演習、出撃、遠征用の装備プリセットを自動切替
* 自動出撃モード (Sortie mode: Auto) &mdash; 日/週/月次任務を自動完了（KC3 が必要）
* 自動遠征モード (Expedition mode: Auto) &mdash; 遠征艦隊の自動切り替えとリソース調整
* 7-4 およびイベント海域対応
* 各種バグ修正 (艦隊切替モジュール、interaction_mode、任務処理、LBAS モジュール等)
