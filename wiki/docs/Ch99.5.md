## Appendix ‐‐ KC3 on POI

After all, we still think KC3 is easier to use than the plugin env in POI,  
so here we are, a work around to run KC3 in POI.

The concept is to run KC3 in an empty old chromium, 
then we clone apis from POI and feed to KC3. 

![kc3 on poi overview](assets/kc3_on_poi_overview.png)

---

### Dependency 

You need to install 

* poi browser (of cause lol)
* `poi-plugin-forwarder`
* Old Chromium which support V2 manifest (mine is Version `138.0.7204.183`)
* KC3 (of cause lol)

### Setup guide

Head to `poi-plugin-forwarder`, 
enable `KC3 relay`

![relay enable](assets/poi-plugin-forwarder-kc3-relay.png)

After installing KC3 on Chromium, 

Now boot up Chromium with the following options:

```bash
chromium --app="http://127.0.0.1:9224/relay.html" --auto-open-devtools-for-tabs --disable-background-timer-throttling --disable-renderer-backgrounding --disable-backgrounding-occluded-windows --no-first-run
```
You should see a blank screen like this.

![kc3 on poi overview](assets/kc3_relay_page.png)

Then you can open KC3's F12 panel.
