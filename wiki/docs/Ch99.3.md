## Appendix ‐‐ Noro6 equipment update

Since Noro6 doesn't get update after you upgrade an equipment,  
after time you will get spam by the following warning:  

<img width="545" height="27" alt="image" src="https://github.com/user-attachments/assets/e2aee350-47da-4988-9e0a-d397b4a3663c" />

This article provides the usage of an semi-auto script in kcauto_custom's tool box,  
which is meant to saves you effort from updating Noro6's equipment data manually.

---

### Overview

The idea of this script is to automatically click the update button for each config in noro6,  
so that you're sync with the equipment you have in stock.

<img width="392" height="149" alt="image" src="https://github.com/user-attachments/assets/56d313a3-6991-497b-9a33-93e77f7a05ed" />
    
***Equipment update function in Noro6***

### Preparation

#### Updating equipment data
First we need to grab the latest data from POI

![Exporting data from POI](assets/poi-plugin-noro6-exporter_button.png)

***Exporting data from POI***

#### Access control
Only tabs opened would be handle by this script,  
in other words,  
you could simply close a config if you don't wish to update it's equipment.

<img width="190" height="138" alt="image" src="https://github.com/user-attachments/assets/92874406-0fad-4d92-bbc0-9a596b0648b8" />

#### Auto save

You would want to **turn on auto save in setting panel** so that every file is saved after the script finished it's job.

***Auto save option in Noro6***

Select `Keep` option for equipment replace policy,  
this case it would be easier for kcauto_custom to tell if an equipment is missing.

Open F12 panel, head to `console` panel,

<img width="393" height="208" alt="image" src="https://github.com/user-attachments/assets/84e45b65-936c-4eac-8cf4-04e17d12f374" />

### Running the script (Tampermonkey)

Alternatively, you can install a Tampermonkey script for convenient one-click execution without opening DevTools every time.

Install the [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) extension in your browser.

![tampermonkey_install](assets/tampermonkey_install.png)

Open Tampermonkey dashboard, click Create a new script.  
Then paste the Noro6 Turbo Sync userscript [code](https://github.com/XVs32/kcauto_custom/blob/develop/tool/noro6_equipment_update_tampermonkey.js). 

![tampermonkey_script_save](assets/tampermonkey_script_save.png)

_Save the script (Ctrl+S) and make sure it is enabled._

Navigate to Noro6(XVs32's edition) page: [https://xvs32.github.io/kc-web/#/aircalc](https://xvs32.github.io/kc-web/#/aircalc)

A floating panel will automatically appear at the bottom-right corner.  
Click ⚡ Turbo Sync All Tabs to start the batch update.

![tampermonkey_script_usage](assets/tampermonkey_script_usage.png)

_Floating panel injected by Tampermonkey script_
