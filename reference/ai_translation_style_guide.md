# 翻譯風格指南 (AI Translation Style Guide)

給 AI 的 prompt 指示：請在進行 zh-TW 與 ja 翻譯時嚴格遵循以下風格規則：
1. 語調與風格 (Tone & Voice)
* 自然流暢、口語化與親和力：避免過度機械化的硬翻譯，保留原文的幽默與社群用語（如 LOL, QAQ, 只能88）。  
* 簡潔俐落：句尾與小結語使用簡短有力的表達（例如原文 That's it! 譯為「以上！」而非「就這麼簡單！」）。  
* 保留情境警示：警告與警示語句語氣要直接且微帶幽默（如 如果不確定自己在做什麼，後果自負，LOL）。  

2. 格式與標點符號規範 (Formatting & Punctuation)
* 中英文/數字間距：中文與英文單字、數字之間必須加入半形空格（例如：在 debug 模式下、Python 3.11 與 pip）。  
* 保留原文連結與註記結構：日期、連結與參考文獻的標註結構需精確還原（例如：參數(2023/05/04) [參考來源](url)）。  
* 路徑與程式碼：所有命令列指令、檔名（如 .json）、路徑（如 ./kcauto_cui）原封不動保留，不進行任何翻譯。  

3. 一律使用 4 個反引號（markdown ... ）包裹：確保內層所有包含 JSON、Java、Bash 等程式碼區塊都不會與外層衝突。
